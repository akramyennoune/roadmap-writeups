Course 3 of the Google Cybersecurity Certificate

This one was all about networks — how they're built, how they're protected, and how attackers try to get around that protection.

Some of what I dug into:

 Network fundamentals — the network models that describe how data actually moves from point A to point B
 Network protocols & infrastructure — the rules and hardware that keep everything talking to each other correctly
 Security controls — firewalls, VPNs, and intrusion detection/prevention systems, and how each plays a different role in defense
 Cloud security — because more and more of what a SOC analyst monitors doesn't even live on-prem anymore
 Network architecture & security — pulling all of it together to think about how a network should be designed to actually hold up under attack

Honestly, this was the module where things started clicking — you can't understand what "suspicious traffic" looks like until you understand what normal traffic looks like first. That's the foundation this course builds.
